## 二、邪修核心五大方法论（为什么21天能速成）

```
                     ┌──────────────────────────┐
                     │   邪修汉语 5 大记忆术    │
                     └─────────────┬────────────┘
         ┌───────────────────┬─────┴─────────────┬───────────────────┐

  1. 汉越词天然外挂   2. 18+ 神经刺激钩子  3. 越南语超拟真空耳  4. 5大万能填空框架
  (60%词汇换腔即懂)   (高多巴胺终身不忘)   (完全无需拼音基础)   (50新词爆出千句)
```

1. **汉越词借力法（60%词汇零成本秒杀）**
   - 越南工人不是欧美零基础老外，他们从小说的词汇中：**质量** (chất lượng)、**问题** (vấn đề)、**生产** (sản xuất)、**安全** (an toàn)、**经理** (kinh lý)、**合格** (hợp cách)、**机器** (máy móc/cơ khí) **全都早已掌握**！
   - 教材直接标注汉越词密码，工人只需换个中国声腔读出来，华人管理层 100% 听得懂。

2. **成人幽默/高感官荒诞记忆钩子（加大胆量，过目不忘）**
   - 科学研究证实：**带有轻度性暗示、荒诞生理反应、强烈夸张画面感的记忆信息，神经突触连接强度是正统教材的 7 倍以上**。
   - 例 1：**打卡 (dǎkǎ)** → 空耳 **"Đá cà"**（Đá vào cà - Đá vào hòn dái）→ 每天早起 7 点困得要死，一到厂门口就像被**踢爆蛋蛋**一样疼醒，瞬间清醒冲到打卡机前刷卡！
   - 例 2：**干杯 (gānbēi)** → 空耳 **"Gan bay"**（Uống đến mức gan bay ra ngoài）→ 敬酒喝到肝都飞出来了，老板见你这么拼，当场拍板提拔！
   - 例 3：**涨工资 (zhǎng gōngzī)** → 空耳 **"Trảng gung gi"**（Tráng dương bổ thận cày ngày cày đêm）→ 身体强壮白天替老板扛线、晚上生龙活虎，老板不涨工资良心过得去吗！

3. **越式空耳拟音注音（Phiên âm bồi chuẩn xác）**
   - 绝不强求声调四个调值，完全采用越南人日常生活中的拼写字母进行最贴近的发音标注，辅以“中国腔调整提示”。

4. **五大万能句型框架（搭积木式指数级繁殖）**
   - `我要 / 我想 + [动作]`（Ủa dao / Ủa xưởng...）→ 明确表达诉求；
   - `有没有 + [物品]？`（Dẩu mấy dẩu...?）→ 调取物料、工具、打听奖金；
   - `这个 + [物品] + 多少 + [单位]？`（Chưa cưa... tua sao...?）→ 盘点库存、询问数量与工时；
   - `因为 + [原因]，所以 + [结果]`（Dân uây..., sủa ỷ...）→ 高情商汇报与合理解释；
   - `请帮我 + [动作]`（Chỉnh bang ủa...）→ 向上求助与下发指令。

5. **工厂升职实战心计学（第三阶段的灵魂）**
   - 普通课程只教你怎么“当好一颗螺丝钉”，本教材教你**“怎么抢到螺丝批”**：
   - 敬酒时杯沿必低于老板 1 公分（`您随意，我干了`）；
   - 出事绝不当场顶撞，先认错再甩给客观原因（`对不起是我的疏忽，主要是仓库没来料`）；
   - 主动找老板立军令状（`让我当组长，产量提两成`）。

## 三、21天课程进阶架构

### 阶段一：生存模式（Day 1 - 7）——听懂指令，不被骂，保住全勤奖
- **Day 1**: 考勤与时间（打卡、加班、迟到、我想请假、下班了）
- **Day 2**: 听懂指令·动作篇（快一点、停一下、搬过去、再来一次、听我说）
- **Day 3**: 听懂指令·位置篇（放这里、拿给我、放在那里、拿走吧、在哪里）
- **Day 4**: 质量与返工（不合格、坏了、重做、检查一下、合格了）
- **Day 5**: 机器与物料（机器坏了、没有料了、去领料、工具在哪、叫维修工）
- **Day 6**: 安全与生理需求（小心危险、我去上厕所、喝水、吃饭了、累死了）
- **Day 7**: 第一周大复盘+实战生存考核（5幕实战长句联调演练）

### 阶段二：主动出击（Day 8 - 14）——能汇报、能求助、展现担当
- **Day 8**: 极简自我介绍（我叫阿雄、我做这个三年了、我学得很快、我很听话、请多关照）
- **Day 9**: 求助与确认（我不会做、请教我、请再说一遍、是这个吗、我听懂了）
- **Day 10**: 汇报工作进度（做完了、还没做完、有点问题、还要半小时、今天超产了）
- **Day 11**: 请假与调换班（我身体不舒服、家里有急事、我想换班、绝不耽误事、下周我补上）
- **Day 12**: 数字与数量（多少个、一百个、差五个、这一箱、数量不够）
- **Day 13**: 日期与交期（今天必须要、明天早上交、几点交货、周末加不加班、什么时候发工资）
- **Day 14**: 第二周大复盘+管理层汇报考核（组合拳实战演练）

### 阶段三：升职加薪（Day 15 - 21）——情绪价值、酒桌艺术、锁定组长席位
- **Day 15**: 夸奖与情绪价值（主管太厉害了、跟着你学到很多、老大辛苦了、老板眼光真好、跟你干真有前途）
- **Day 16**: 表达野心与上进心（我想多学点、让我试试看、我不怕累、我想负责这条线、我随时随地能顶上）
- **Day 17**: 酒桌饭局升职密码（我敬主管一杯、您随意我干了、吃好喝好、祝老板生意发大财、我喝倒了也陪您）
- **Day 18**: 谈钱不伤感情（加班费怎么算、这个月有奖金吗、表现好能涨工资吗、老板不会亏待我、最近物价太贵了）
- **Day 19**: 申请升职做组长（老大我想当组长、大家都服我、我能管好这条线、保证不出错、给我个机会证明）
- **Day 20**: 冲突化解与甩锅艺术（对不起是我的疏忽、下次我一定注意、不是我不做是没物料、别生气消消气、我马上改过来）
- **Day 21**: 毕业实战·与老板一对一谈话秘籍（5分钟闭环独白拿下任命书）

## 四、如何使用与交付

### 1. 手机端 / 电脑端直接打开学习（A 方案）
- 双击根目录下的 [`index.html`](file:///d:/Anti-workspace/hanyu-xiexiu/index.html)，任何主流浏览器（Chrome、Edge、Safari、手机浏览器）均可直接打开。
- **发音功能**：无需联网安装庞大音频文件，点击任何句子旁边的 `🔊` 按钮，浏览器内置语音合成器（Web Speech API）即会以地道普通话发音朗读。
- **打卡记录**：工人在手机上勾选“已掌握”或“完成今日任务”，进度会自动保存在手机本地储存中（LocalStorage）。

### 2. 工厂打印工牌速查卡（B 方案）
- 双击打开 [`pocket-cards.html`](file:///d:/Anti-workspace/hanyu-xiexiu/pocket-cards.html)。
- 在右上角下拉框选择想要打印的天数（如“Tuần 1: Sinh tồn”或“Toàn bộ 21 Ngày”）。
- 点击右上角 **"🖨️ In Ra Giấy / Xuất PDF"**，在打印窗口中选择保存为 PDF 或直接用 A4 彩色/黑白打印机输出。
- 沿卡片四周的虚线剪下，塞进厂牌（工卡套）背面，上班带进车间，随看随用！
